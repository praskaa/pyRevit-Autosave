# AutoSave

AutoSave protects pending changes in Revit by saving the user's working copy.

## Language

**Local save**
A save of the user's working copy. For file-based worksharing, this is the local RVT. For cloud worksharing, this is the working copy Revit keeps in its local cache.

**Synchronize with Central**
The Revit operation that exchanges changes between the working copy and the shared central model.
